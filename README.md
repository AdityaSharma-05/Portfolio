# Aditya Kumar — Portfolio

Personal portfolio website built with Astro, TypeScript, and modern CSS.

## Routes

- `/` — homepage
- `/about` — about, skills, education, and current focus
- `/projects` — selected projects

## Development

```bash
npm install
npm run dev
```

Build the static site:

```bash
npm run build
```

Project content is centralized in [`src/content.ts`](./src/content.ts). See [`AGENTS.md`](./AGENTS.md) for instructions for future AI-assisted updates and [`WEBSITE_GUIDE.md`](./WEBSITE_GUIDE.md) for editing guidance.
